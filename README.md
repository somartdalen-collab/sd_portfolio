# Somart Dalen Portfolio

A clean, responsive personal portfolio for Somart Dalen, WEP student at PNC.

## Files

- `index.html` — semantic page structure and SEO metadata
- `css/style.css` — responsive design and animations
- `js/script.js` — mobile menu, active navigation, reveal animations, demo contact form
- `robots.txt` — search crawler instructions
- `sitemap.xml` — sitemap for search engines
- `images/` — add your real profile/project images here

## Before hosting

1. Replace `https://your-domain.com/` in `index.html`, `robots.txt`, and `sitemap.xml` with your real domain.
2. Replace the profile placeholder with your own professional image.
3. Replace `#` project/social links with real URLs.
4. Connect the contact form to a backend or form service if you want messages to be delivered.
5. Add real project screenshots to `images/`.
6. Test the website on mobile and desktop.
